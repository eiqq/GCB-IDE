# GCB Skript

게임캐릭터배틀(파오캐) 서버의 Skript 코드용 VSCode 확장.
워크스페이스의 `.sk` 파일을 훑어서 함수·이벤트·표현식 인덱스를 만든다. 서버 경로를 하드코딩하지 않으므로 각자 자기 스크립트 폴더를 열면 그대로 동작한다.

## 기능

- **함수 자동완성** — `function` 정의 전부. 고르면 인자 자리가 스니펫으로 깔린다.
- **이벤트 표현식 자동완성** — 커서가 있는 `on <이벤트>:` 블록에서 실제로 쓸 수 있는 표현식만 목록 맨 위에. 별칭과 `set` 가능 여부까지 표시.
- **옵션 자동완성** — `{@...}` 는 현재 파일 `options:` 블록 것만. 값도 같이 보여준다.
- **파라미터 힌트** — `(` / `,` 에서 시그니처 팝업. 선언 뒤 `#주석`을 설명으로 같이 보여준다.
- **정의로 이동 / 호버** — 함수·표현식 둘 다.
- **구문 강조** — 함수명·파라미터·타입·`{_지역변수}`·`{전역변수}`·`{@옵션}`·이벤트 표현식을 각각 다른 색으로. 인덱스에 없는 함수 호출은 색이 안 들어와서 오타가 눈에 띈다.

## 설치

Releases 에서 `.vsix` 를 받아 VSCode 확장 탭 → `…` → **Install from VSIX...**
또는:

```
code --install-extension gcb-skript-<버전>.vsix
```

소스에서 직접 빌드하려면 (파이썬만 있으면 된다, npm 불필요):

```
python pack.py
code --install-extension gcb-skript-<버전>.vsix --force
```

**소스 폴더를 `.vscode\extensions` 안에 두지 말 것** — 설치 과정에서 그 경로가 지워진다.

## 설정

| 키 | 기본값 | 설명 |
|---|---|---|
| `gcbSkript.roots` | `[]` | 워크스페이스 밖에서 추가로 인덱싱할 폴더 절대경로 |
| `gcbSkript.exclude` | `**/node_modules/**` | 인덱싱 제외 glob. 참고용 원본 사본까지 열려 있으면 여기서 뺀다 |
| `gcbSkript.showLocalFunctions` | `true` | 현재 파일의 `local function` 도 자동완성에 포함 (다른 파일 것은 절대 안 나옴) |

이름이 `-` 로 시작하는 파일·폴더는 Skript 가 로드하지 않으므로 인덱스에서도 제외한다.
저장할 때마다 그 파일만 다시 인덱싱한다. 전체 재인덱싱은 `Ctrl+Shift+P` → "GCB Skript: 함수 인덱스 다시 만들기".

## 개발

```
node test.js "<스크립트 폴더 경로>"
```

파싱 로직 테스트 + 실제 코퍼스 개수 검증. VSCode 없이 돈다.
